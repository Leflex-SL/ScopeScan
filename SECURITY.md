# Security policy

Security fixes target the current development version. Release support windows
will be listed here when a release maintenance policy is established.

Report vulnerabilities privately to the repository maintainers. Use GitHub's
private vulnerability reporting for https://github.com/Olmen023/ScopeScan when
available, or contact the maintainer through their GitHub profile to agree a
private channel. Do not include credentials, target identities or exploitable
private infrastructure details in public issues.

Include the affected version/commit, a minimal reproduction using a local fixture,
expected/actual behavior and impact. Never scan third-party systems to demonstrate
a report. The project has no guaranteed response SLA at present.

Deployment guidance: [Panel security](docs/panel-security.md).
Export contract and handling: [Data and evidence](docs/data-and-exports.md).
